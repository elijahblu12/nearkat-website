# NEARKAT

Source for the official [NEARKAT website](https://nearkat.xyz).

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

## Update the community wall

1. Add the new image to `public/gallery/` and `site/gallery/`.
2. Add its filename to `public/gallery/gallery.js` and `site/gallery/gallery.js`.
3. Commit and deploy the update.

The wall is owner-curated and does not accept public uploads.
